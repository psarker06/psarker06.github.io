# Team Images

Place team member images in this directory.

## File naming convention:
- Use lowercase with underscores
- Format: `firstname_lastname.jpg` or `firstname_lastname.png`
- For placeholder: Use `placeholder.jpg`

## Recommended image specifications:
- Format: JPG or PNG
- Size: 400x400 pixels minimum
- Aspect ratio: 1:1 (square)
- File size: Less than 500KB

## Current team members:
- Director profile image should be placed in `/assets/img/` as `profile.jpg`
- Other team member images go here in `/assets/img/team/`

## Example:
```
/assets/img/team/
├── john_doe.jpg
├── jane_smith.jpg
├── placeholder.jpg
└── README.md
```
